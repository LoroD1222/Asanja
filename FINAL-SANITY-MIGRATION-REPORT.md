## Remaining production configuration requirements

The content migration is complete, but production preview and revalidation still require owner-supplied deployment details:

1. Confirm the canonical production website origin and the deployed Studio origin.
2. Add a Sanity Viewer token directly to the Next.js host as the server-only `SANITY_API_READ_TOKEN`. Do not send it through chat.
3. Generate and store a server-only `SANITY_REVALIDATE_SECRET`, then configure the matching Sanity webhook for article, author, category and tag mutations.
4. Set public Next.js variables for project `mduy4p4u`, dataset `production`, and the deployed Studio URL.
5. Set `SANITY_STUDIO_PREVIEW_ORIGIN` to the confirmed website origin before building the deployed Studio.
6. Add the exact production website and Studio origins to Sanity CORS as required; do not use a wildcard.
7. Review the 169 drafts in Studio and publish only through a separate, explicit editorial approval process.
8. Revoke the short-lived migration write token now that verification is complete.
